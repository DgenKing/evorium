# Web3D asset pipeline

The game is plain ES modules served by FastAPI: no runtime Node, npm, bundler or CDN.
The asset tools below run from the **repository root**. They never save the kit `.blend`.

Prerequisites: Blender 4.3+ on PATH (built with 5.3.0), Node 24/npm, Python/Pillow,
Chrome, and both Quaternius **Standard** zips in `~/Downloads/evorium-characters/`.
Unlock the read-only kit at `/run/media/user/Data Storage/Evorium/AncoatsKit/Ancoats_Blender_Kit/`.
The pack licence files must say CC0. Standard currently contains Superhero bodies,
not the Regular bodies in the original brief. Those male/female bodies are tinted
with a height-based clothing mask. The library contains 43 clips; ten are shipped.
Both skeletons have matching animation bone names, so no retargeting is required.
A broken `_png.png` texture URI in the pack is repaired with the supplied corresponding PNG.

## Rebuild from the original downloads

```bash
mkdir -p tools/web3d/raw/characters
python3 - <<'PY'
from pathlib import Path
from zipfile import ZipFile
for path in (Path.home() / 'Downloads/evorium-characters').glob('*.zip'):
    with ZipFile(path) as archive:
        archive.extractall('tools/web3d/raw/characters')
PY
npm ci --prefix tools/web3d --registry=https://registry.npmjs.org
(cd tools/web3d/raw && npm pack three@0.187.0 --registry=https://registry.npmjs.org && tar -xzf three-0.187.0.tgz)
node tools/web3d/vendor.mjs
blender -b '/run/media/user/Data Storage/Evorium/AncoatsKit/Ancoats_Blender_Kit/Ancoats.blend' -P tools/web3d/export_set.py -- --out tools/web3d/raw
node tools/web3d/build_characters.mjs
blender -b -P tools/web3d/bake_lighting.py
bash tools/web3d/optimise.sh
```

`npm ci` installs only build tools under the ignored `tools/web3d/node_modules`.
The vendor script copies only used official Three.js **0.187.0** files and its MIT
licence. This release supplies no minified build: the requested
`three.module.min.js` filename contains its unmodified `three.module.js`, plus
its required `three.core.js` sibling. No production dependency is installed.

`raw/blend_inventory.txt` lists every collection/object, compares 15 waypoints
against the supplied Blender-metre coordinates (5 cm tolerance), checks floors
and open doorways, and records the waist-ray-verified walking grid. Both street
ends must reach every marker, tested by Node. Blender text signs are evaluated as
meshes at low curve resolution to avoid excessive lettering tessellation. Only
the active Street scene and selected set objects export; cast/other scenes do not.
`raw/characters_inventory.txt` lists meshes, materials, bone names and clip durations.

Cycles CPU bakes indirect lighting at 128 samples into a second UV atlas (2048 high,
1024 low); if diffuse baking fails, the script attempts AO. Night uses a reduced
lightmap intensity, emissive windows and runtime lights, with no separate night bake.
The atlas packs the whole set: small props have limited texel density.
The optimizer keeps named pub/shop interiors, glass and sign groups, reduces
low geometry, deduplicates, welds, prunes and resamples, compresses with Meshopt,
and converts textures to WebP. Collision is exported separately as 44 simple hulls.

`data/budgets.json` is generated by the pipeline. It fails above 12 MB / 150k
triangles for low or 30 MB / 400k for high. These are downloaded asset geometry
counts (one male and one female); actual visible actors and shadow passes are
reported separately by Chrome. Texture estimates include mipmaps and the atlas;
they exclude renderer buffers, JavaScript and octree memory. Measure on real phones
before calling the iOS memory target verified. The vendor modules add about 2.4 MB
uncompressed; HTTP compression can reduce transfer. Raw files are ignored by git.

Measured results and screenshot review: [VERIFICATION.md](VERIFICATION.md).

## Verify without the real API

```bash
node tests/world3d.test.mjs
.venv/bin/python -m pytest -q
node tests/map_view.test.cjs
bash tools/web3d/run_checks.sh
```

`run_checks.sh` owns a fake smoke server on `127.0.0.1:8011`, makes a consistent
SQLite **read-only backup** into `/tmp/evorium-smoke/smoke.sqlite3`, disables auto,
and substitutes fake clients before importing the app. It never changes the live
save, `config.py`, website or Unreal project. It refuses an occupied 8011.
`EVORIUM_SMOKE_DB` optionally changes the copy location. Never set it to the live save.
`POST /smoke/at` exists only in this fake process, for deterministic clock/routine checks.

Chrome is controlled through Node's built-in WebSocket/CDP. Twenty PNGs and JSON
reports (street/pub/shop/cast/player × low/high × 1280×720/390×844) go to
`tools/web3d/raw/screens/`. The runner checks ready/error state, expected public
NPC IDs, a scripted capsule walk through both doors, jump/landing, masonry,
closed doors, camera collision, fake chat, and 60× routine changes. Pillow rejects
blank captures. Use `--movement-only` for one quick view and functional checks,
or `--screens-only` for captures without writes to the fake copy.

Headless SwiftShader is software rendering; its FPS is diagnostic, not phone or
GTX 1060 performance. Real iOS Safari memory, keyboard and multi-touch feel require
physical-device review. If Snap Blender or local sockets are sandbox-blocked,
run these commands with the session's approved external access.
