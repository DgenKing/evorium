# Evorium

An AI-driven living world: eight characters on a Manchester street who talk, remember, make decisions and carry
on without you. Python + FastAPI + SQLite + DeepSeek, with a dashboard, a 2D map and a 3D browser game.

**Everything about the project is in [EVORIUM.md](EVORIUM.md):** how it works, how to run it, the home server,
the 3D game, known issues, next steps and the full history.
