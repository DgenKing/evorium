# Evorium

An AI-driven living world on a Manchester street. Python + FastAPI + SQLite + DeepSeek, with a dashboard, a 2D
map and a 3D browser game.

## Meet the APCs

Evorium's characters aren't scripted NPCs. They're **APCs: AI Player Characters**, with lives, memories and
ambitions of their own. They talk to each other when you're not there, make plans, keep and break promises, and
remember who was kind and who wasn't. They don't exist to serve you. You're simply another person in their
world.

**Everything about the project is in [EVORIUM.md](EVORIUM.md):** how it works, how to run it, the home server,
the 3D game, known issues, next steps and the full history.
